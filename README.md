# dompekin-delivery

Плагин WordPress: вызов курьера Достависты по Business API 1.5 после принятия оплаченного заказа в WooCommerce.

## Важно про этот репозиторий

Репозиторий **публичный** (требование бесплатной версии Deployer for Git). Здесь только код плагина.

Не коммитить:

- токены Достависты (тестовый и боевой) — они хранятся в настройках сайта;
- секрет callback-уведомлений;
- адреса, телефоны, номера заказов, выгрузки базы;
- документацию по инфраструктуре сайта, доступы, конфигурацию хостинга.

## Установка через Deployer for Git

1. Создать публичный репозиторий с этой папкой в корне (файл `dompekin-delivery.php` на верхнем уровне).
2. В WordPress: Deployer for Git → добавить репозиторий, ветка `main`.
3. Тип: **plugin**, путь назначения: `wp-content/plugins/dompekin-delivery`.
4. Первый деплой — вручную кнопкой, не автоматом.
5. Проверить, что плагин появился и активируется.
6. Только после этого включить Push-to-Deploy.

Не направлять деплой в корень `wp-content`, в тему `blocksy-child` или в общую папку `plugins`.

## Настройка плагина

WooCommerce → Dompekin Delivery:

1. Адрес и телефон ресторана (точка забора).
2. Токен, среда — **Тестовая**.
3. «Проверить геокодер сейчас».
4. Диагностика адреса по ID заказа.
5. Автовызов включать последним.

## Поведение

- Доставка создаётся только после подтверждённой оплаты и принятия заказа (`_dp_stage = cooking`).
- Идемпотентность: одна попытка на заказ и среду, атомарная резервация в базе.
- Неизвестный результат отправки не повторяется автоматически.
- Уведомления принимаются по `/wp-json/dpd/v1/callback` с проверкой HMAC.
- Заказ не завершается автоматически по событию «доставлено».
